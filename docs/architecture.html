1. Purpose / how to read this file

This is the system design index for the running box. It exists so the code on main and Brad’s mental model stay the same document.

Use the sticky index on the left. Every heading is an in-page anchor. This is not a second site — the path is still docs/architecture.html.

Rule. If this page and the Python disagree, the Python on origin/main wins. Status chips mark shipped write-only 403 / not entitled not built so design intent is not mistaken for running code.

High-level first. Formula pages are stub anchors only — no derivations here. No pandas lecture, no secrets, no API keys.

2. Repo layout

Three Python packages plus tests and ops scripts. Jobs are python -m ingest.jobs.<name> from a venv, not an installed distribution.

PathWhat it is
ingest/ Capture. REST, delayed websocket, S3 flat files, schemas, cron jobs, entitlements probe.
marketdata/ Typed reads of clean parquet. OPRA parse, Contract/Quote/Forward, catalog as-of, fail-loud validate.
pricing/ Calculators, not a surface. BSM catalog, IV invert, Engine (European analytic / American CRR), from_market, drift_check.
tests/ Offline pytest: ingest, tests/marketdata/, tests/pricing/, plus Healthchecks/crontab drift tests.
docs/ This handbook only (architecture.html).
deploy/ crontab (source of schedule) and an optional systemd unit for the websocket job.
scripts/ bootstrap, backfill, repair, prune_raw, Healthchecks setup. Not a package.

There is no surfaces/, no rates package, no ClickHouse client. The schemas module mentions ClickHouse in a docstring; no DDL ships.

4. Ingest

Three pipes into one disk tree. Everything live is 15-minute delayed. Cron is the scheduler; flock prevents overlap. Shared runner is ingest.common.cli.run_job (settings, market gate, JSONL logs, per-job Healthchecks /start and /fail).

websocket REST S3 flat file

Massive / Polygon constraints that affect design

  • One delayed-options websocket slot. Wildcards AM.O:SPY* ACK and deliver nothing; subscribe explicit AM.O:<ticker> in chunks of 3,000.
  • No X-RateLimit-* headers; 429s happen under burst. Shared token bucket (MASSIVE_MAX_RPS default 40) plus retries.
  • Auth is ?apiKey=; pagination next_url omits the key — the client re-appends it.
  • SPXW weeklies list under underlying_ticker=SPX / snapshot path I:SPX. Querying SPXW as an underlying returns 0 rows.
  • Same-day SPY equity minute aggs 403 → underlying_bars is T-1. Intraday SPY lives on the option snapshot’s underlying_price.
  • I:SPX / I:VIX index levels 403 everywhere. SPX spot is recovered from put-call parity on the chain → clean/forwards.
  • Option NBBO REST and quotes_v1 flat file are 403. No bid/ask, no mid. Market price is last trade else day close.
  • Timestamps stored exactly as delivered (ns/ms epoch, UTC). Never converted in ingest.

Entitlements

Probed, not assumed. Re-check with python -m ingest.entitlements (exit 1 on drift in either direction: something stopped working, or something newly available that no job captures). This absorbed the former ingest.smoke, so it is also the post-bootstrap and post-credential-change check.

A 200 is not sufficient: response bodies are shape-checked, so an endpoint that answers but stops returning the fields the jobs read counts as drift. Option probe paths resolve a live contract at run time rather than naming one, because a fixed ticker returns an entitled-but-empty 200 once it expires — indistinguishable from a revoked entitlement. Missing or placeholder S3 keys SKIP (exit 0) rather than FAIL, so a half-configured box reports "not set up yet" instead of a verdict about the plan.

Entitled
Contracts (incl. expired), full-chain snapshots with greeks/IV/OI, option trades, option aggs, T-1 equity minutes, grouped daily, dividends/splits, market status, delayed options WS, trades_v1 / minute_aggs_v1 / day_aggs_v1.
Not entitled
Option NBBO (REST and quotes_v1), I:SPX / I:VIX (and other I:* index levels), equity trades/quotes, us_stocks_sip, same-day equity aggs, /v1/indicators/*.

5. marketdata

Typed parquet I/O. Import submodules directly (marketdata.opra, .types, .catalog, .validate). CLI: python -m marketdata.validate (same as python -m marketdata).

OPRA allowlist
Allowlist is exactly SPY, SPX, SPXW. The parser alternation is longest-first (SPXW before SPX) so O:SPXW… is not captured as SPX. A prefix match on O:SPY would admit SPYL/SPYS/SPYG; parse_opra does not. Raises OPRAParseError — never a partial.
Contract
Exercise style and multiplier live on the dataclass: SPY American, SPX/SPXW European, multiplier 100. Settlement instants: SPY/SPXW 16:00 ET, SPX monthlies 09:30 ET (AM-settled).
Quote
Snapshot-derived. Vendor IV/greeks copied as diagnostics (vendor_*). market_price = last if present, else day close. Pricing must ignore vendor columns.
As-of
Snapshots/contracts/forwards are written many times a day. read_partition refuses those datasets (double-count). read_asof takes the last file per underlying at or before asof_ns (filename epoch-ms). Absence is an error.
Fail-loud
Extra or missing parquet columns → SchemaError. Validate fails on foreign roots, mixed underlyings vs a SPY-only query, required-nulls, empty allowlisted root, empty table. --roots narrows the allowlist; it cannot extend it.

6. pricing

Calculators. Not a surface, not an interpolator. Pass S, K, T, r, q (or F) and sigma explicitly.

GreeksConventions
Defaults: vega per 1.00 vol, theta per year of calendar time, spot delta/gamma. Dual (∂/∂K) is always also populated. Tests that read a Greek must name the convention.
Named catalog
price; 1st delta, dual_delta, vega, theta, rho, rho_dividend; 2nd gamma, dual_gamma, vanna, volga, charm, veta, vera; 3rd speed, zomma, color, ultima; elasticity.
European vs American
Engine protocol: EuropeanBSM closed-form; AmericanCRR tree with bump-and-revalue Greeks. Style comes from the contract (SPY American, SPX/SPXW European).
IV invert
Newton with bounds, Brent fallback. Price outside discounted no-arbitrage bounds → ValueError. Never returns NaN. European BSM only — there is no American IV solver.

7. Warehouse → math chain

python -m pricing.from_market --date YYYY-MM-DD --asof-ns N --r 0.04

  • Loads last option_snapshots and forwards at or before that instant.
  • Inverts own IV from last/close (no NBBO mid).
  • Computes own Greeks. SPX/SPXW → European BSM; SPY → American CRR (default 51 tree steps on the chain).
  • --spy-atm-pct CRR-prices only ATM SPY and European-prices the rest. --max-rows caps American CRR rows only so an SPX-first concat cannot starve SPY.
  • Vendor greeks_* / implied_volatility copied as diagnostics with signed diffs (own − vendor). Theta × 365 and vega × 100 for unit alignment. Never inputs.
  • T is ACT/365 from as-of to the settlement instant (not UTC midnight of the expiry date).
  • --r is a required scalar. No rates warehouse.
  • SPX has no snapshot spot: parity forward → Black-76 via synthetic S = F e^{-rT}.
  • Exit nonzero on foreign roots, mixed underlyings, required-nulls, empty allowlisted root, schema drift, or (unless --skip-uninvertible) a price outside bounds.

8. Daily canary

python -m pricing.drift_check at 17:00 ET Mon–Fri, after the 16:35 EOD snapshot. As-of is the last snapshot at or before 16:40 ET.

Pass/fail is identity-first on ATM names (|K/F − 1| ≤ 5%):

  • Reprice: market_price vs stored own_price (CRR for American rows, BSM for European).
  • European pairs: Γ_call ≈ Γ_put and vega_call ≈ vega_put at a shared σ (mean of the two inverted IVs), plus PCP on day-close quotes vs S e^{-qT} − K e^{-rT}. PCP is skipped when either leg used a last-trade (possibly a different instant).
  • FAIL when median reprice error exceeds its band, or >25% of ATM names fail identities. Too few ATM names (< 20) is also FAIL.

Vendor diffs are diagnostic. Null vendor IV is not a FAIL (vendor_compare_skipped). Vendor drift can FAIL only with enough vendor-comparable ATM names. Still fail-loud on no snapshots, schema errors, foreign roots, empty allowlisted root, filesystem errors.

Cron bounds: --spy-atm-pct 0.05, --max-rows 400 (CRR rows only). --r from DRIFT_CHECK_R (default 0.04). Report: _meta/drift_check.json + JSONL under logs/drift_check/. Exit 1 pings Healthchecks massive-drift-check /fail; optional DRIFT_ALERT_WEBHOOK (Slack-wrapped if the URL is hooks.slack.com). Holidays: skip with exit 0 unless --force.

11. Formula stubs

Future anchors. Derivations live in pricing/, not here.

BSM price / d1 / d2 — pricing.bsm. Continuous r, q; or F via F = S e^{(r−q)T}.
IV invert — pricing.iv.implied_vol. Newton, then Brent. Bounds: discounted intrinsic. Never NaN.
CRR tree — pricing.engine.crr_price. American early exercise; risk-neutral p outside [0,1] is an error, not clipped.
Parity forward — ingest.jobs.forward_from_parity. Undiscounted approximation F = K + C − P at the strike minimising |C−P|. Exact parity is F = K + erT(C − P); the job uses the approximation.
Year fraction — pricing.from_market.year_fraction. ACT/365 to settlement instant.
Vendor unit align — theta × 365 (day → year), vega × 100 (1% → 1.00). Same in from_market diffs and drift_check.
