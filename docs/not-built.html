Do not treat these as missing files in a half-landed feature — they are not in the tree.

Curves and calendars

ItemStatusWhat exists instead
Vol surfaces / interpolator not built The ATM curve is built — atm_term_structure, one row per (date, root, expiry), 2022-08-31 onward. There is still no smile fit and no interpolator, so there is nothing to evaluate off-strike or between expiries.
Rates warehouse / curve built rates_sync lands treasury_yields; ingest.common.rates.rate_for is what every IV inversion discounts with. History is walked back to 1962, so historical dates resolve properly (2022-08-31 → 2.4%, 2023-05-10 → 5.47%). DRIFT_CHECK_R remains only as the canary's scalar override.
Holiday calendar for T / trading-day theta not built Pricing T is still ACT/365 and 252 is still a constant, not a calendar — nothing here is trading-day aware. A verified historical calendar does now exist as a by-product of history_audit (_meta/trading_days.json, every weekday since 2022-08-31 marked session or holiday against the vendor), so the input for trading-day theta is available even though nothing consumes it. The ingest gate still uses _meta/holidays.json, which only covers upcoming dates.

Market data and pricing

ItemStatusWhat exists instead
NBBO mid not entitled Quote.market_price = last else close.
American IV solver built pricing.iv.implied_vol_american inverts the CRR tree by Brent. SPY sigma now comes off the same engine that prices it; a price at intrinsic returns 0.0, because an American put exercised now is worth that at every sigma.
Index levels (I:SPX, I:VIX, …) 403 Parity forwards on the option chain.
