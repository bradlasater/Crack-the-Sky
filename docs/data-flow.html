Data flow

← overview

Capture lands parquet under DATA_ROOT. Math never reads the vendor’s IV/greeks as inputs. The canary re-runs the same chain every weekday at 17:00 ET.

1 parquet

clean/ under DATA_ROOT (default /data/massive)

2 as-of

marketdata.catalog.read_asof — last file ≤ instant, per underlying

3 own IV

European BSM invert of last/close. Never NaN; never vendor σ

4 own Greeks

SPX/SPXW analytic BSM; SPY American CRR (ATM slice on cron)

5 canary

pricing.drift_check — ATM identities first; vendor diffs optional

python -m pricing.from_market  →  python -m pricing.drift_check

Irreplaceable
option_snapshots (+ derived forwards). No historical snapshot endpoint. Sweep every minute.
Backfillable
trades, minute bars, day bars from S3. Flat file always wins at reconcile.
Write-only today
contracts_expired, underlying_day_bars. Captured; nothing in pricing/marketdata consumes them yet.
Now consumed
forwards is no longer write-only — from_market joins per-expiry parity F.
Derived
atm_term_structure — one row per (date, root, expiry), built from option_day_bars by pricing.term_structure. Not captured: the whole archive rebuilds in ~7 minutes via scripts/build_term_structure.py, so it is safe to delete and safe to recompute after any change to the reduction. Built from day bars rather than snapshots precisely because day bars reach back to 2022-08-31 while snapshots only begin in 2026.
