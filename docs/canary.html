Daily canary

← overview

python -m pricing.drift_check at 17:00 ET Mon–Fri, after the 16:35 EOD snapshot. As-of is the last snapshot at or before 16:40 ET.

Pass/fail is identity-first on ATM names (|K/F − 1| ≤ 5%):

  • Reprice: market_price vs stored own_price (CRR for American rows, BSM for European).
  • European pairs: Γ_call ≈ Γ_put and vega_call ≈ vega_put at a shared σ (mean of the two inverted IVs), plus PCP on day-close quotes vs S e^{-qT} − K e^{-rT}. PCP is skipped when either leg used a last-trade (possibly a different instant).
  • FAIL when median reprice error exceeds its band, or >25% of ATM names fail identities. Too few ATM names (< 20) is also FAIL.

Vendor diffs are diagnostic. Null vendor IV is not a FAIL (vendor_compare_skipped). Vendor drift can FAIL only with enough vendor-comparable ATM names. Still fail-loud on no snapshots, schema errors, foreign roots, empty allowlisted root, filesystem errors.

Cron bounds: --spy-atm-pct 0.05, --max-rows 400 (CRR rows only). --r from DRIFT_CHECK_R (default 0.04). Report: _meta/drift_check.json + JSONL under logs/drift_check/. Exit 1 pings Healthchecks massive-drift-check /fail; optional DRIFT_ALERT_WEBHOOK (Slack-wrapped if the URL is hooks.slack.com). Holidays: skip with exit 0 unless --force.
