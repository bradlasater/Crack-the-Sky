marketdata

← overview

Typed parquet I/O. Import submodules directly (marketdata.opra, .types, .catalog, .validate). CLI: python -m marketdata.validate (same as python -m marketdata).

OPRA allowlist
Allowlist is exactly SPY, SPX, SPXW. The parser alternation is longest-first (SPXW before SPX) so O:SPXW… is not captured as SPX. A prefix match on O:SPY would admit SPYL/SPYS/SPYG; parse_opra does not. Raises OPRAParseError — never a partial.
Contract
Exercise style and multiplier live on the dataclass: SPY American, SPX/SPXW European, multiplier 100. Settlement instants: SPY/SPXW 16:00 ET, SPX monthlies 09:30 ET (AM-settled).
Quote
Snapshot-derived. Vendor IV/greeks copied as diagnostics (vendor_*). market_price = last if present, else day close. Pricing must ignore vendor columns.
As-of
Snapshots/contracts/forwards are written many times a day. read_partition refuses those datasets (double-count). read_asof takes the last file per underlying at or before asof_ns (filename epoch-ms). Absence is an error.
Fail-loud
Extra or missing parquet columns → SchemaError. Validate fails on foreign roots, mixed underlyings vs a SPY-only query, required-nulls, empty allowlisted root, empty table. --roots narrows the allowlist; it cannot extend it.
