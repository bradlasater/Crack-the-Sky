Top level

Three Python packages plus tests and ops scripts. Jobs are python -m ingest.jobs.<name> from a venv, not an installed distribution.

PathWhat it is
ingest/ Capture. REST, delayed websocket, S3 flat files, schemas, cron jobs, entitlements probe.
marketdata/ Typed reads of clean parquet. OPRA parse, Contract/Quote/Forward, catalog as-of, fail-loud validate.
pricing/ Calculators, not a surface. BSM catalog, IV invert, Engine (European analytic / American CRR), from_market, drift_check, term_structure (the ATM curve — still not a surface: no smile fit, no interpolator).
tests/ Offline pytest: ingest, tests/marketdata/, tests/pricing/, plus Healthchecks/schedule drift tests.
docs/ This handbook: index.html plus one page per section, and box-operations.html for off-repo machine state.
deploy/ schedule.json (source of schedule), crontab (kept installed through the timer cutover), the Ansible playbook + unit templates that generate the systemd timers, and an optional systemd unit for the websocket job.
scripts/ bootstrap, backfill, repair, prune_raw, Healthchecks setup, build_term_structure.py (rebuilds the ATM curve over the archive). Not a package.

Not in the repo

There is no surfaces/, no rates package, no ClickHouse client. The schemas module mentions ClickHouse in a docstring; no DDL ships.
