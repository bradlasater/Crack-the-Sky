Ingest

← overview

Three pipes into one disk tree. Everything live is 15-minute delayed. Cron is the scheduler; flock prevents overlap. Shared runner is ingest.common.cli.run_job (settings, market gate, JSONL logs, per-job Healthchecks /start and /fail).

websocket REST S3 flat file

Massive / Polygon constraints that affect design

  • One delayed-options websocket slot. Wildcards AM.O:SPY* ACK and deliver nothing; subscribe explicit AM.O:<ticker> in chunks of 3,000.
  • No X-RateLimit-* headers; 429s happen under burst. Shared token bucket (MASSIVE_MAX_RPS default 40) plus retries.
  • Auth is ?apiKey=; pagination next_url omits the key — the client re-appends it.
  • SPXW weeklies list under underlying_ticker=SPX / snapshot path I:SPX. Querying SPXW as an underlying returns 0 rows.
  • Same-day SPY equity minute aggs 403 → underlying_bars is T-1. Intraday SPY lives on the option snapshot’s underlying_price.
  • I:SPX / I:VIX index levels 403 everywhere. SPX spot is recovered from put-call parity on the chain → clean/forwards.
  • Option NBBO REST and quotes_v1 flat file are 403. No bid/ask, no mid. Market price is last trade else day close.
  • Timestamps stored exactly as delivered (ns/ms epoch, UTC). Never converted in ingest.

NY cron

Source of truth: deploy/crontab. TZ=America/New_York. Cron does not expand ~ — rewrite the literal home path before crontab deploy/crontab. MAILTO="" in the checked-in file (set a mailbox on the box if you want cron mail on nonzero exits). What is actually installed on the box, and the drift alarm that keeps it honest: box operations.

Healthchecks: one check per job, slug massive-<job> (underscores → hyphens). Ping key in .env; a leftover HEALTHCHECKS_PING_URL without a ping key is rejected at Settings.load (exit 2). Setup script scripts/setup_healthchecks.py must match crontab job names (CI asserts that).

Entitlements

Probed, not assumed. Re-check with python -m ingest.entitlements (exit 1 on drift in either direction: something stopped working, or something newly available that no job captures).

Entitled
Contracts (incl. expired), full-chain snapshots with greeks/IV/OI, option trades, option aggs, T-1 equity minutes, grouped daily, dividends/splits, market status, delayed options WS, trades_v1 / minute_aggs_v1 / day_aggs_v1.
Not entitled
Option NBBO (REST and quotes_v1), I:SPX / I:VIX (and other I:* index levels), equity trades/quotes, us_stocks_sip, same-day equity aggs, /v1/indicators/*.

Smoke

python -m ingest.smoke — six live checks: config, market status, contracts, snapshot flatten, T-1 SPY minute aggs, S3 head-bucket. Placeholder S3 keys SKIP (exit 0) rather than FAIL. Run after bootstrap or credential change.
