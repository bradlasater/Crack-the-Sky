data_ingest_infra

Warehouse → math chain

← overview

python -m pricing.from_market --date YYYY-MM-DD --asof-ns N --r 0.04

  • Loads last option_snapshots and forwards at or before that instant.
  • Inverts own IV from last/close (no NBBO mid).
  • Computes own Greeks. SPX/SPXW → European BSM; SPY → American CRR (default 51 tree steps on the chain).
  • --spy-atm-pct CRR-prices only ATM SPY and European-prices the rest. --max-rows caps American CRR rows only so an SPX-first concat cannot starve SPY.
  • Vendor greeks_* / implied_volatility copied as diagnostics with signed diffs (own − vendor). Theta × 365 and vega × 100 for unit alignment. Never inputs.
  • T is ACT/365 from as-of to the settlement instant (not UTC midnight of the expiry date).
  • --r is a required scalar. No rates warehouse.
  • SPX has no snapshot spot: parity forward → Black-76 via synthetic S = F e^{-rT}.
  • Exit nonzero on foreign roots, mixed underlyings, required-nulls, empty allowlisted root, schema drift, or (unless --skip-uninvertible) a price outside bounds.
